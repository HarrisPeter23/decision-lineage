## D-30 (2026-11-08) H1 primary metric changed before FREEZE: cited-lineage F1 instead of cited lineage completeness
Decided by the user before any F1 number existed, regardless of how it would affect my system (metric code committed in b1e006b before it was run). **Reason:** cited lineage completeness alone rewards breadth and is gameable (citing everything scores 1.0). On DEV the static-graph ablation scored above the full system on retrieval-level completeness (0.69 vs 0.63), and vector_rag came close with about 9x more evidence. **New primary:** cited-lineage F1 over the pooled headline types, averaged per set, paired bootstrap over sets (10,000 resamples, seed 0), Holm over 2 tests (vs evowiki_style, vs graphiti). Cited completeness (recall), cited precision and completeness@k (k = median DEV-gold lineage length per type) move to the secondary family. DEV values were computed once, for information (FREEZE section 14); the metric does not change after this.
